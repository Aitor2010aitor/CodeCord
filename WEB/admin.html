🛡 Moderación y AutoMod

Configura los filtros de AutoMod para censurar mayúsculas, palabras prohibidas, imágenes y las acciones automáticas al banear o expulsar miembros.

Filtros de AutoMod Activa y configura cada tipo de censura automática.
Censura de Mayúsculas Detecta y borra mensajes con exceso de mayúsculas.
Palabras Prohibidas Detecta y borra palabras o frases prohibidas.
Censura de Imágenes Elimina enlaces de imágenes y archivos adjuntos.
Canales donde aplicar la censura Si no seleccionas ninguno, se aplica en todo el servidor. Mantén Ctrl para seleccionar varios.
Acciones al Detectar Infracción Qué hace el bot cuando censura un mensaje.
Acciones de Moderación Comportamiento del bot al ejecutar comandos de ban o kick.
🔨 Eliminar mensajes al banear Elimina el historial de mensajes de los últimos 7 días del usuario al banearlo.
🎿 Eliminar mensajes al expulsar Elimina el historial de mensajes de los últimos 7 días del usuario al expulsarlo (kick).
Rol Automático al Entrar Asigna un rol automáticamente a los miembros nuevos cuando se unen al servidor.
🛡 Sistema Antiraid (12 Módulos)

Monitoriza 12 tipos de acciones. Cuando un usuario supera el límite configurado, el bot le quita todos los roles (aislamiento) y ejecuta la acción (ban/kick) automáticamente.
⚠️ El rol del bot debe estar por encima de los roles de los usuarios objetivo.

¿Qué es esto? Aquí pones los IDs de usuarios que NO quieres que el antiraid toque. Ejemplo: IDs de bots, administradores, o usuarios de confianza. Separa cada ID con una coma.
Los logs del antiraid NO se configuran aquí. Debes ir a la sección Logs para configurar el canal donde se enviarán

Configuración del rol no verificado y acceso automático a canales

🔍

Rol de No Verificados

Selecciona el rol que tienen los usuarios no verificados. Cuando se cree un canal nuevo en el servidor, el bot automáticamente configurará ese canal para que ese rol no pueda verlo, protegiéndolo hasta que el usuario se verifique.

El bot necesita tener el permiso Gestionar Canales para aplicar esta configuración automáticamente.

Este rol se quitará del usuario tan pronto como complete la verificación (reacción o OAuth2).
