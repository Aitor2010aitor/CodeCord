/help Todos

Muestra la lista de comandos disponibles, guías interactivas y documentación de uso.

Uso: /help [módulo] Slash
/ban Admin / Mod

Sanciona y expulsa permanentemente a un usuario infractor con registro automático en logs.

Uso: /ban [usuario] [razón] Sanción
/ticket setup Admin

Despliega un panel interactivo de soporte en el canal deseado con botones personalizables.

Uso: /ticket setup [canal] Panel
/embed create Mod

Abre el constructor interactivo con editor de título, descripción, color hex y previsualización en vivo.

Uso: /embed create [canal] Diseño
/warn Mod

Registra una advertencia formal y aplica auto-silencio si el infractor acumula el límite configurado.

Uso: /warn [usuario] [motivo] AutoMod
/sorteo Mod

Inicia un sorteo con temporizador automático, botón de entrada y elección criptográfica justa.

Uso: /sorteo [tiempo] [ganadores] [premio] Giveaway
/backup create Owner Only

Genera un respaldo completo de la estructura del servidor protegido con cifrado y clave de restauración.

Uso: /backup create Seguridad
/autorole Admin

Asigna automáticamente un rol predefinido a nuevos miembros o bots al ingresar al servidor.

Uso: /autorole [rol] Auto
/clear Mod

Elimina de 1 a 100 mensajes de un canal con opciones de filtro por usuario, bots o enlaces.

Uso: /clear [cantidad] [filtro] Purge
