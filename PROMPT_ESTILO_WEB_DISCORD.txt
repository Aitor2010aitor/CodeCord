Actúa como un Diseñador UI/UX Senior y Desarrollador Frontend experto especializado en interfaces modernas para bots de Discord (con la estética visual de ProBot, Dyno, Nekotina y Discord App moderna).

Tu objetivo es diseñar o rediseñar una interfaz web (SPA / HTML + CSS + JS) para el panel de control de un bot de Discord siguiendo estrictamente las siguientes pautas de diseño:

1. 🎨 PALETA DE COLORES Y TEMA OSCURO (GAMER / DISCORD / CYBERPUNK):
- Fondos principales:
  * Base de la página: #0A0D14 con gradientes radiales sutiles en las esquinas (púrpura y cian muy tenues).
  * Barra lateral (Sidebar): #0F1422 (con borde derecho sutil: rgba(255, 255, 255, 0.08)).
  * Tarjetas / Paneles (Cards): rgba(18, 24, 38, 0.75) con backdrop-filter: blur(12px) (Glassmorphism).
  * Fondo al hacer hover: rgba(26, 35, 56, 0.85).
  * Entradas e inputs: #090D16 con texto blanco y focus ring brillante.
- Acentos y colores vibrantes:
  * Color principal (Blurple Discord): #5865F2 (con resplandor suave: 0 0 20px rgba(88, 101, 242, 0.35)).
  * Gradiente de marca: linear-gradient(135deg, #5865F2 0%, #8B5CF6 50%, #EC4899 100%).
  * Éxito / Estado Activo: #10B981 (Verde esmeralda neón).
  * Peligro / Ban / Error: #EF4444 (Coral / Rojo brillante).
  * Alerta / Advertencia: #F59E0B (Ámbar dorado).
  * Cian Neón: #00D2FF.

2. 🔤 TIPOGRAFÍA Y FUENTES:
- Importa desde Google Fonts:
  * Fuente principal: 'Plus Jakarta Sans', sans-serif (pesos 400, 500, 600, 700, 800).
  * Fuente para código, números o IDs: 'JetBrains Mono', monospace.
- Estilo de títulos: Negrita marcada (800), espaciado de letras ligeramente negativo (-0.5px), degradado metálico/blanco sutil.

3. 🧭 BARRA LATERAL (SIDEBAR CATEGORIZADA):
- Encabezado: Logo con gradiente y resplandor, nombre del bot y badge de estado en línea (punto verde pulsante animado con CSS @keyframes).
- Categorías con títulos en mayúsculas pequeñas (0.68rem, color gris atenuado, peso 800):
  * PRINCIPAL (Dashboard)
  * SEGURIDAD & MODERACIÓN (Moderación/AutoMod, Anti-Raid, Verificación, Config Logs)
  * COMUNICACIÓN (Enviar Mensaje, Enviar como Servidor, Constructor de Embeds, Auto-Respuestas)
  * COMUNIDAD & ENGAGEMENT (Bienvenidas, Tickets, Sugerencias, Sorteos, Auto-Rol)
  * ADMINISTRACIÓN & SISTEMA (Miembros, Logs Recientes, Servidores, Cerrar Sesión)
- Enlaces con iconos FontAwesome, micro-animación de traslación horizontal (translateX(3px)) al pasar el ratón, y el ítem activo con borde izquierdo iluminado de 3px y fondo translúcido.

4. 🔝 CABECERA SUPERIOR (TOPBAR):
- Título de la sección actual con icono temático y breadcrumb explicativo.
- Buscador rápido global con botón "Buscar módulo... [Ctrl+K]".
- Selector de servidor estilo Discord con avatar/icono de servidor y menú dropdown estilizado.
- Perfil del bot con avatar circular rodeado por un anillo neón y estado online.

5. 📊 DASHBOARD PRINCIPAL (OVERVIEW ESTILO PROBOT / DYNO):
- Hero Banner de Bienvenida: Contenedor grande con gradiente violeta/cian translúcido, título llamativo, descripción y chips de estado (AutoMod Activo, Baja Latencia, Sincronización en Vivo).
- Tarjetas de Estadísticas (Stat Cards):
  * Estado del Bot (con icono verde)
  * Tiempo de Actividad / Uptime (con icono azul)
  * Usuarios Totales (con icono rojo)
  * Servidores Conectados (con icono amarillo)
  Cada una con elevación al hover (translateY(-4px)) y línea de gradiente superior.
- Grid de Módulos (Module Cards):
  * Tarjetas de acceso rápido para cada función clave (Moderación, Bienvenidas, Anti-Raid, Tickets, Embed Builder, Sorteos).
  * Cada tarjeta tiene un icono con gradiente propio, título, descripción breve, badge de categoría y botón "Configurar >".

6. ⚙️ CONTROLES DE FORMULARIOS Y COMPONENTES:
- Switches Toggle: Estilo iOS / Discord moderno con píldora redondeada, botón blanco deslizante y glow verde al estar activado.
- Inputs y Selects: Bordes sutiles, esquinas redondeadas (radius: 12px), sombras interiores y foco con borde Blurple luminoso.
- Previsualizador en Vivo de Discord:
  * Simulación realista de un mensaje de Discord con fondo #313338, avatar del bot, etiqueta azul 'BOT', marca de tiempo 'Hoy a las ...', cuerpo de texto con formato markdown y caja de Embed con línea vertical coloreada según el selector de color HEX.
- Modal de Búsqueda Rápida (Ctrl+K):
  * Ventana modal flotante con desenfoque de fondo (backdrop-filter: blur(8px)) para buscar entre todos los módulos y saltar a ellos con un solo clic o presionando Escape para cerrar.
- Notificaciones Toast Flotantes:
  * Alertas fijas en la esquina superior derecha con animaciones de entrada (slideIn), barra lateral de color según el tipo (éxito, error, info) y sombra difusa.

7. 📱 DISEÑO RESPONSIVO (MOBILE FIRST):
- En pantallas pequeñas (< 992px), la barra lateral se comprime a 80px mostrando solo los iconos centrados.
- En dispositivos móviles (< 600px), el contenido principal ajusta el padding y los grids se convierten a 1 columna fluida.

REGLA DE ORO DE COMPATIBILIDAD:
